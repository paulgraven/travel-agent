# Personal Travel Agent

Static interactive prototype and local MCP tool starter. **Not a finished ChatGPT app**. No live integrations or bookings.

## Deployment
1. Keep the GitHub repository private.
2. Import it into Vercel with Framework Preset: Other.
3. Enable deployment protection before entering any real travel information.
4. Connect GitHub to Vercel for automatic deployments from main.

The Python `server.py` is a local MCP prototype and is **not** deployed by the static Vercel site. A secure, hosted MCP endpoint and custom embedded UI still need implementation.
